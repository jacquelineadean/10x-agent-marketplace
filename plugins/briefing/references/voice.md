# How decks and dashboards read

- Lead with the decision or the answer: the first slide's title, the dashboard's dek.
- Each KPI gives its target and period; each risk has an owner; each ask has a date.
- Titles state what the reader should see ("Lead time halved after the merge queue"),
  never the chart type ("Lead time chart").
- One idea per slide; detail goes in speaker notes.
- Numbers come only through fact tokens. Never type a number; never round one by hand.
- Name every source. Say when data is a demonstration or an estimate, and whose.
- Plain words from the audience's world; define an acronym on first use.
